# suml — 숨을 고르는 기록

김이막의 마음 회복 웰니스 브랜드를 위한 챌린지 운영 MVP입니다.

## 포함된 흐름

- 참여자의 오늘의 미션, 인증 상태, 마음 기록
- 진행비 입금 및 환급 조건 상태 표시
- 주간 회복 리포트와 개인 기록 히스토리 진입점
- 인스타그램 연동 상태 표시
- 로컬 브라우저에 마음 기록 임시 저장

## 실제 운영 연동 전 필요한 설정

이 정적 MVP를 실제 서비스로 확장할 때는 Supabase(Auth, Postgres, Storage)를 연결해 회원·기록·인증을 안전하게 보관하고, 결제사 API로 입금 및 환급을 처리해야 합니다. 인스타그램 팔로우 확인은 Meta의 승인된 Instagram Graph API 범위와 사용자의 OAuth 동의가 필요합니다. 자동 환급은 서비스 운영 계좌에 직접 접근하지 않고, 승인된 결제사의 정산/환불 API를 통해 구현해야 합니다.

## 배포

정적 사이트이므로 Vercel에서 이 저장소를 Import하면 별도 빌드 설정 없이 바로 배포됩니다.
